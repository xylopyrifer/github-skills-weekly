# GitHub Skills Weekly

**中文** · [English](README.en.md) · [访问网站](https://xylopyrifer.github.io/github-skills-weekly/)

发现 GitHub 上热门 AI Agent Skills，了解它们能做什么，并按功能找到适合自己的工具。

## 功能

- 中英文切换；最近 5 周热榜和长期累计榜。
- 查看项目用途、Stars、Forks、周增长及排名变化。
- 按名称、简介和功能标签搜索，按热度、Stars、更新时间或名称排序。
- GitHub 登录后选择已有标签，或通过“其他”添加自定义标签。

## 更新与标签

每天北京时间 **08:00** 启动数据更新，周一结算上周榜单。GitHub 调度可能延迟，页面显示实际采集时间。

自定义标签提交并发布成功后即可公开展示，无需等待审核。每周审核一次：符合项目用途的标签保留；也可由上周不同支持账号数**超过仓库估算访客数的三分之一，且至少 5 人**而保留；不符合的移除。资料不足时暂缓，不因采集失败删除。每个账号只计一次，重复提交替换旧选择。每次最多填写 5 个自定义标签，每个 2–32 字。自定义标签在中英文界面保留原文。

系统标签、访客提交与审核决定分别保存，页面合并统计。审核采纳的标签成为项目的持续标签，即使原提交撤回也保留；拒绝记录避免下次同步重新显示。现有固定功能词表继续自动更新。每周内容审核由本项目的 Codex 自动任务执行；复制仓库部署时，需要另行配置审核任务。

正式周榜使用相邻周一快照计算增长。开站前的历史回溯单独标识，不计入正式累计分；正式数据积累后会自然替换首页回溯展示。每天覆盖最新资料，周榜摘要长期保存，原始周快照保留约 8 周。

## 本地运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
```

`npm test` 验证代码，`npm run build` 生成可部署的 `dist/`。支持 GitHub Pages 和普通静态服务器。

详细部署、评分和维护说明：[开发文档（中文）](docs/DEVELOPMENT.zh.md) · [Developer guide (English)](docs/DEVELOPMENT.en.md) · [标签审核](docs/TAG-REVIEW.md)。自动发布流程保留在 `.github/workflows/`，日常使用不需要手动操作。
